Signal Line - installable offline version

1. Upload every file in this folder to one folder on any static web host that serves HTTPS
   (GitHub Pages, Netlify, Cloudflare Pages, your own server).
2. On the iPad, open the address in Safari.
3. Share button > Add to Home Screen.
4. Open the game once from the home screen icon while online. After that it works offline.

Updating: replace index.html and change VERSION in sw.js (for example signal-line-v3).
Progress and custom levels are stored on the device by the installed app.

Replacing an earlier Nightfall Telegraph upload: overwrite all files in the same folder. Installed copies update the next time they are opened online; close and reopen once more to see the new version.
